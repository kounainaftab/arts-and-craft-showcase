# 🎨 Arts and Crafts Showcase Web App

A beautiful and simple web app built with Python and Streamlit to upload, display, and explore creative arts and crafts. Perfect for artists, hobbyists, or teachers to share their work in a gallery format.

---

## 🚀 Features

- 🖼️ Upload artwork or craft images with a name and description
- 🧵 View all uploaded items in a responsive gallery layout
- 💾 Automatically saves uploaded images to a local folder
- ✅ Easy-to-use sidebar form for adding new items

---

## 🛠️ Technologies Used

- **Python 3**
- **[Streamlit](https://streamlit.io/)** – for building the web UI
- **Pillow (PIL)** – for image handling
